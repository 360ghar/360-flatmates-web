### Review pass (after the first summary)
A second review found and fixed: `AbortSignal.any` crash on Safari < 17.4 (critical), sign-out leaving the stored session after a failed revoke, lost match/error results and over-eager rollback with overlapping swipes, reused temp ids for failed chat sends, the map filtering by the Home city, draft resurrection after publish, uploads timing out together, navigation after leaving the page, invented city counts still in the static SEO HTML, the compatibility page crashing on a partial or null-score response (also on `main`), nav tab labels off their shared baseline (conflicting `gap-*` classes: `cn()` does not merge Tailwind classes), keyboard-only swipe guide on touch devices, opacity-0 entrances and hover movement left in a few components, icon tiles, hover-only photo actions (unreachable on touch), `text-body-sm` used but never defined, and `paper-2` / `paper-3` / `clay-soft` values that disagreed with DESIGN.md.

### Deviations from the plan
- Scene art is generated path data (`art.ts`) from one Python script, not SVG files; the same script emits the Flutter op-codes.
- No `PaperSurface` component: `Card` covers it.
- Token values adjusted for AA: clay `#A94A2B`, clay-press `#8C3B20`, dark ink-3 `#A39C91`, clay-soft `#F6E6DE`.
- Legacy token names kept as aliases: `paper` = sky, `surface-soft` = paper-1, `surface` = paper-2, `surface-elevated` = paper-3, `accent` / `primary` = clay.

### Product decisions taken
- Removed the testimonials section: the quotes, names and match scores were invented.
- Removed the hard-coded city listing counts on the landing page (not real data).
- Removed the TrustStrip and ComparisonFlow sections and the mascot PNGs; the paper scene replaces them.
- The OG image and logo are now rendered manually (`npm run generate:og-image`, output committed) instead of on every build.

### Redesign (Paper Diorama)
- Tokens: `src/styles/globals.css` implements DESIGN.md §1–§7 (light + pine-black dark). Legacy names alias the new palette. AA contrast is enforced by `src/styles/__tests__/contrast.test.ts`.
- Type: Gambarino (display, self-hosted woff2) + `system-ui` body; Inter removed.
- Primitives: `PaperScene` (9 layers, scroll parallax, still under reduced motion), `PaperMiniScene` (empty/error states), cut-paper nav icons, grain, torn and scalloped edges, press/lift.
- Components restyled: Button, Card, Input, Chip, Toggle, SegmentedControl, Badge, Toast, Modal/Drawer/BottomSheet, Skeleton, EmptyState/ErrorState, OfflineBanner (in-flow), AppShell nav, ThemeToggle, Logo.
- Screens: landing (diorama hero, paper steps, FAQ slips, torn paper footer), auth (night/day neighbourhood), profile header scene, app screens (cut radii, no icon tiles, scene per empty state).
- Motion never hides content: entrance keyframes and framer-motion `initial` states are translate/scale only (the swipe hint and match card were fixed in the review pass).
- Controls never move on hover (swipe buttons, avatar edit, store badges, blog chips fixed in the review pass); cards use the 1 px `paper-lift`.

### Remaining issues / next steps
1. Browser Back during a dirty form: migrate to `createBrowserRouter` and use `useBlocker`.
2. Backend: unread notification count, server-side admin search, confirm support for the extra map filters.
3. Add a CSP report endpoint (`report-to`), watch it, then switch from Report-Only to enforcing.
4. Replace the remaining lucide utility icons with a bespoke set (only the 13 nav/sidebar icons are custom; they are generated from `scripts/generate-paper-art.py` and shared with the Flutter app).
5. Re-render the `.wiki` overview video with the new tokens.
6. Explore map tiles show "API key required" from CARTO in local dev (pre-existing tile configuration).
7. `cn()` concatenates classes without merging, so a later Tailwind class does not override an earlier one of the same kind. Consider `tailwind-merge` in `cn()`, then re-check component overrides.
8. The swipe card still pins a role badge and a score ring on the photo; consider moving the role into the name line.
